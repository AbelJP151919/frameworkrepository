# ProyectoCine_ReactVite

Esta es una página web de ejemplo para la gestión y visualización de películas, desarrollada con React y Vite.

## ¿Qué hace esta página?

Permite mostrar una lista de películas, ver detalles y navegar entre diferentes secciones como inicio, películas, contacto y sobre nosotros.

## ¿Cómo ejecutar el proyecto?

1. Instala las dependencias:

   ```bash
   npm install
   ```

2. Inicia el servidor de desarrollo:

   ```bash
   npm run dev
   ```

3. Abre tu navegador en la URL que aparece en la terminal (por defecto suele ser [http://localhost:5173](http://localhost:5173)).
